## 发布方式（GitHub Pages）

仓库已配置自动发布：

- 当 `main` 分支有新提交时，会自动触发 GitHub Actions 部署
- 部署成功后可通过仓库的 GitHub Pages 地址访问网页（入口为 `index.html`）

### 首次启用

1. 打开仓库 **Settings → Pages**
2. 在 **Build and deployment** 中将 Source 设为 **GitHub Actions**
3. 推送一次新提交，等待 `Deploy static site to Pages` 工作流完成
